# ForgeGUI_Core High-Value Widget Expansion

Priority additions after the current rail/workbench foundation:

1. Command palette / omnibox across commands, panels, assets, files, and settings.
2. Quick switcher for open documents and recent assets.
3. Dock compass with live drop-target preview.
4. Panel hover actions: pin, soft-lock, detach, focus-fill, overflow.
5. Tab preview thumbnails with dirty/error/status indicators.
6. Peek panel for temporary Inspector/asset detail.
7. Property grid with mixed values, reset/revert, validation, provenance, and undo.
8. Numeric scrubbers with units, ranges, expressions, and step metadata.
9. Asset-reference picker with thumbnail/search/recent.
10. Virtualized Explorer/Asset Browser with tree/list/grid modes.
11. IDE-style document-map scrollbar with search/error/bookmark markers.
12. Sticky Inspector/Browser section headers.
13. Inline diff viewer with split, before/after, and overlay modes.
14. Pinnable popovers that can become persistent mini-panels.
15. Bottom auto-hide console/Cortex tray with drag/hover expansion.
16. Notification inbox plus transient toasts.
17. Compact command-progress/status pill.
18. Workspace presets and Focus Mode.
19. Drag ghost with exact target/reorder preview.
20. Empty/loading/error/skeleton states as first-class components.
21. Timeline/dope-sheet/keyframe/event-marker controls.
22. Node cards, ports, wires, subgraph breadcrumbs, and graph minimap.
23. Universal 2D/3D canvas rulers, guides, snapping HUD, gizmos, and navigator.
24. Palette/history strip for recent colors/assets/materials.
25. Theme/DPI/density/reduced-motion certification matrix.
26. 3D camera orientation cube and perspective/orthographic toggle.
27. Measurement and annotation overlays.
28. Runtime-state/debug overlay host.
29. Consumer-extensible viewport tool shelf.
30. Input/chord visualization for keyboard-first discoverability.
